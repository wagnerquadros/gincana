## 🤝 Contribuição

### 🌟 Como contribuir
1. Crie uma branch a partir de `develop`:
   ```bash
   git checkout develop
   git pull origin develop
   git checkout -b feature/nome-da-feature
   ```

2. Desenvolva seguindo o [Style Guide](#-style-guide-styleguidemd).

3. Faça commits semânticos conforme definido no [Workflow](#-workflow-workflowmd).

4. Envie sua branch:
   ```bash
   git push origin feature/nome-da-feature
   ```

5. Abra um Pull Request (PR):
   - Descreva o que foi feito
   - Marque revisores
   - Aguarde aprovação antes do merge

### ✅ Checklist do PR
- [ ] Código formatado (ESLint/Prettier)  
- [ ] Testes rodando localmente  
- [ ] Documentação atualizada (se necessário)  
- [ ] Nenhum erro crítico no lint
